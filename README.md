# Project IVA

**Project IVA** (Intelligent Virtual Assistant) is a cross-platform Flutter application built to serve as a personal assistant. It is designed to work seamlessly across Android, iOS, and desktop platforms like Windows. The app is still in early development but aims to integrate features such as voice commands, speech-to-text, task management, and more.

---

## ✨ Features

- 🧠 Voice-based interaction (planned)
- 📝 Speech-to-text transcription
- 📅 Basic task or note handling (planned)
- 💬 Clean Flutter UI
- 🔄 Cross-platform compatibility (mobile & desktop)
- 🚧 *Work in progress – more features coming soon!*

---

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (version 3.x or later recommended)
- Dart SDK (comes with Flutter)
- Android Studio or Visual Studio Code (for development)
- Platform-specific tools:
  - Android: Android SDK + emulator or device
  - iOS: Xcode + iOS simulator or device
  - Windows: Visual Studio with C++ build tools (for desktop support)

---

### Installation

1. **Clone the repository**

```bash
git clone https://github.com/Maricbrass/Project_IVA.git
cd Project_IVA

```
2. **Install dependencies**
```bash
flutter pub get
```

3. **Run the app**
```bash
flutter run
```
